# PULIKOV — сборка мебели
Персональный сайт Дмитрия Пуликова на React, TypeScript и Vite.

## Локальный запуск
- Node.js 20+
- `npm install`
- `npm run dev`

## Сборка
`npm run build`

## Перед публикацией
Заменить демонстрационные изображения на реальные фотографии работ, добавить подтверждённые отзывы и актуальные контакты. Форма сейчас готовит сообщение и открывает WhatsApp только после того, как указан номер в настройке `CONTACT_PHONE` в `src/App.tsx`. Укажите действующий номер перед использованием.
